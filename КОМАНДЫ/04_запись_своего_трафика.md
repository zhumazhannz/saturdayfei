# 04. Записать трафик своего компьютера

Записывать можно **только свой компьютер и свою сеть**.

Перед записью: закрыть торрент-клиент (uTorrent и т. п.) — он похож на ботнет; выключить VPN;
в браузере выключить «безопасный DNS» (Chrome: Настройки → Конфиденциальность и безопасность → Безопасность).

**1. Открыть PowerShell от имени администратора:** Пуск → набрать `PowerShell` → «Запуск от имени администратора».

**2. Начать запись:**
```
pktmon start --capture --pkt-size 0 -f $HOME\Documents\my.etl
```

**3.** Пользоваться компьютером 3–5 минут (или запустить скрипт из шага 06 / 07).

**4. Остановить запись и сохранить в формате pcap:**
```
pktmon stop
```
```
pktmon etl2pcap $HOME\Documents\my.etl -o $HOME\Documents\my.pcapng
```

Дальше — файл `05_анализ_своей_записи.md`.

## Если ошибка
- `Access is denied` — окно открыто не от администратора. Проверка: `net session` должна не ругаться.
- Если всё равно `Access is denied` — выполнить `pktmon stop` и начать заново.
- Альтернатива: Wireshark (https://www.wireshark.org) → двойной клик по сети → Стоп → File → Save As.
