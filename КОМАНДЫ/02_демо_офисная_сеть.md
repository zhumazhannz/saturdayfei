# 02. Демонстрация: офисная сеть с двумя ботами

Запись сети из 14 компьютеров (30 минут). Двое заражены (necurs и matsnu), программа об этом не знает.

```
python main.py --pcap pcaps/demo/office.pcap --out reports/office.html --no-blacklist
```
```
start reports/office.html
```

Ожидается: два «Вероятно заражён» (риск 0,96–0,97), один «Подозрительный» (программа обновлений), 11 чистых.

Кто заражён на самом деле — в файле `pcaps/demo/office.pcap.truth.json`.

`--no-blacklist` — не подсматривать в чёрный список, решать только по признакам (честный режим для демо).

**Всё одной кнопкой:** двойной клик по `demo.bat` в папке проекта.
