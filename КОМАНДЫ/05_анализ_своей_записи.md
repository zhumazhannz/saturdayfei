# 05. Прогнать свою запись через программу

В **обычном** PowerShell, из папки проекта:
```
python main.py --pcap $HOME\Documents\my.pcapng --out reports\my.html
```
```
start reports\my.html
```

Программа сама уберёт дубли, которые оставляет pktmon (до 90 % пакетов).

**Узнать, какая программа стоит за подозрительным портом** (например, 8886):
```
Get-NetTCPConnection -RemotePort 8886 | Select RemoteAddress, OwningProcess, @{n='Программа';e={(Get-Process -Id $_.OwningProcess).ProcessName}}
```

Отчёт со своим трафиком содержит посещённые сайты — **не выкладывать его в интернет**.
