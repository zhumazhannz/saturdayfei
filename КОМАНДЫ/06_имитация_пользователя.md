# 06. Чистая запись: скрипт сам открывает обычные сайты

Нужно для показа «чистого» компьютера без личных сайтов в отчёте.

**1.** PowerShell **от администратора**:
```
pktmon start --capture --pkt-size 0 -f $HOME\Documents\clean.etl
```

**2.** **Обычный** PowerShell, из папки проекта (3 минуты; для 5 минут добавить `-Minutes 5`):
```
powershell -ExecutionPolicy Bypass -File fake_user.ps1
```

**3.** В окне администратора:
```
pktmon stop
```
```
pktmon etl2pcap $HOME\Documents\clean.etl -o $HOME\Documents\clean.pcapng
```

**4.** Обычный PowerShell:
```
python main.py --pcap $HOME\Documents\clean.pcapng --out reports\clean.html
```
```
start reports\clean.html
```

Ожидается «Чистый» (если торрент-клиент закрыт).
