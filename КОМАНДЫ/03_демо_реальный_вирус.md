# 03. Демонстрация: реальный вредоносный трафик

Запись из открытого набора Stratosphere Lab (авторы CTU-13): заражённое IoT-устройство сканирует Telnet.

```
python main.py --pcap pcaps/real/test7-malicious.pcap --out reports/test7.html
```
```
start reports/test7.html
```

Ожидается: `192.168.2.16` — «Вероятно заражён» (риск 0,79): сканирование, соединения без DNS, нестандартные порты.
