# 01. Установка (один раз)

Нужен Python 3.10+ (https://www.python.org/downloads/, при установке поставить галочку «Add Python to PATH») и Git (https://git-scm.com/download/win).

**1. Скачать проект** (в папку «Документы»):
```
cd $HOME\Documents
```
```
git clone https://github.com/zhumazhannz/saturdayfei.git
```
```
cd saturdayfei
```

**2. Поставить библиотеки:**
```
pip install dpkt pandas scikit-learn joblib
```

**3. Проверить, что всё работает:**
```
python tests/test_pipeline.py
```
Должно напечатать четыре строки `ok ...`.

## Если ошибка
- `python не является ... командой` — Python не установлен или не добавлен в PATH. Переустановить с галочкой «Add Python to PATH».
- `No module named ...` — повторить шаг 2.

Все следующие команды выполняются **из папки проекта** (`cd $HOME\Documents\saturdayfei`).
