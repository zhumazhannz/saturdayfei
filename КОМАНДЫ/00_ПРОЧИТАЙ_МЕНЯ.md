# Команды по порядку

Каждый файл — один шаг. Открываешь, копируешь команду, вставляешь в PowerShell, нажимаешь Enter.
Команды в одном блоке выполняются по очереди, по одной.

| Файл | Что делает | Нужен администратор? |
|---|---|---|
| `01_установка.md` | скачать проект и поставить библиотеки (один раз) | нет |
| `02_демо_офисная_сеть.md` | главная демонстрация: программа находит двух ботов | нет |
| `03_демо_реальный_вирус.md` | настоящая запись заражённого IoT-устройства | нет |
| `04_запись_своего_трафика.md` | записать трафик своего компьютера | **да** |
| `05_анализ_своей_записи.md` | прогнать свою запись через программу | нет |
| `06_имитация_пользователя.md` | чистая запись: скрипт сам открывает обычные сайты | да (для записи) |
| `07_имитация_заражения.md` | «заражённый» компьютер для показа (безопасно) | да (для записи) |
| `08_тесты.md` | проверить, что всё работает | нет |
| `09_эксперименты.md` | пересчитать все цифры из отчёта | нет |
| `10_обучение_детектора_DGA.md` | заново обучить модель | нет |

Если что-то пошло не так — см. раздел «Если ошибка» в конце каждого файла.
