# 07. «Заражённый» компьютер для показа (безопасно)

Скрипт `fake_infected.ps1` ведёт себя как бот, но вредоносного кода в нём нет:
1. перебирает ~100 случайных несуществующих доменов (DGA);
2. каждые ~20 с стучится на `example.com` (маячок к серверу);
3. подключается к IP публичных DNS-серверов без DNS-запроса (резервный канал).
Чужие компьютеры не сканирует и не атакует.

**1.** PowerShell **от администратора**:
```
pktmon start --capture --pkt-size 0 -f $HOME\Documents\infected.etl
```

**2.** **Обычный** PowerShell, из папки проекта (~3,5 минуты, ждать зелёное «Готово»):
```
powershell -ExecutionPolicy Bypass -File fake_infected.ps1
```

**3.** В окне администратора:
```
pktmon stop
```
```
pktmon etl2pcap $HOME\Documents\infected.etl -o $HOME\Documents\infected.pcapng
```

**4.** Обычный PowerShell:
```
python main.py --pcap $HOME\Documents\infected.pcapng --out reports\infected.html
```
```
start reports\infected.html
```

Ожидается красное «Вероятно заражён». Компьютер может появиться дважды (IPv4 и IPv6-адрес) — это один и тот же компьютер.
