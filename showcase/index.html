Анализатор ботнетов PCAP

Программа получает запись сетевого трафика и показывает, какие компьютеры в сети заражены. Она ловит ботов по двум признакам сразу: по «придуманным» доменам (DGA) и по поведению — перебору несуществующих адресов, регулярным «маячкам» к серверу управления, сканированию.

$ python main.py --pcap capture.pcap --out report.html
50 из 50ботов найдено — по одному на каждое семейство DGA из набора UMUDGA
0 из 450чистых компьютеров ошибочно названы заражёнными
0,916F1 детектора DGA на 39 837 доменах (порог энтропии — 0,689)
28 520пакетов в секунду на обычном ноутбуке, без GPU

Как программа работает

Пять модулей, у каждого свой автор. Сырой трафик читает только парсер, остальные работают с таблицами, поэтому две ветви анализа независимы.

Этап 4 · эксперименты

Всё вместе: находит ли программа заражённые компьютеры

Для каждого из 50 семейств собрана отдельная запись: 10 обычных компьютеров, программа-апдейтер и один бот. Ботов проверяли по доменам, которых детектор не видел при обучении, чёрный список отключён.

Апдейтер ни разу не назван заражённым: во всех 50 сценариях он получил вердикт «подозрительный». Регулярные обращения бывают и у честных программ, поэтому решение по нему остаётся за аналитиком.

«Тихий» бот: какая доля найдена

12 ботов шлют всего 20 запросов за полчаса и выходят на связь раз в 5 минут с разбросом ±50 %. Поодиночке ветви анализа пропускают многих, вместе — почти никого.

Честно о слабых местах

Ограничения

  • Словарные DGA. Домены вроде weakgrow.net по имени неотличимы от обычных. Такого бота выдаёт только поведение: перебор несуществующих доменов и маячки.
  • Обычный трафик в сценариях искусственный. Домены настоящие (Tranco, UMUDGA), а расписание посещений сгенерировано. На реальной сети с тысячами пользователей пороги нужно перенастроить.
  • Зашифрованный DNS (DoH/DoT) прячет имена доменов: остаются только признаки соединений.
  • Сервер CTU-13 был недоступен, поэтому из реального вредоносного трафика проверены две небольшие записи Stratosphere. В них нет DGA, но есть сканирование, и его программа нашла.
