# Анализатор ботнетов PCAP

Групповой проект МУИТ: модуль анализа сетевых дампов (PCAP) для выявления ботнет-активности и DGA.

Программа получает запись сетевого трафика и показывает, какие компьютеры в сети, вероятно, заражены, по каким признакам и в каких пакетах это видно.

```
python main.py --pcap capture.pcap --out report.html
```

**Как запустить — папка [`КОМАНДЫ/`](КОМАНДЫ/00_ПРОЧИТАЙ_МЕНЯ.md): готовые команды по шагам, просто копировать и вставлять.**

## Результаты

| Что проверяли | Результат |
|---|---|
| Детектор DGA, 39 837 новых доменов, 50 семейств UMUDGA | F1 **0,916** (порог энтропии — 0,689), ROC-AUC 0,976 |
| 50 сетей, в каждой один бот и 10 чистых компьютеров | найдено **50 из 50** ботов, **0** ложных тревог на 450 чистых |
| «Тихий» бот: 20 запросов за 30 минут | гибрид — **11 из 12**; только DGA — 8, только поведение — 5 |
| Скорость: час трафика 105 компьютеров (85 МБ) | **8,5 с** на обычном ноутбуке |
| Реальный IoT-бот (Stratosphere Lab) | «Вероятно заражён» (сканирование Telnet) |
| Реальный ноутбук участника | 0 сайтов принято за DGA; торрент-клиент — «подозрительный» |

Подробно — [`ОТЧЁТ_ЭТАПЫ_3-5.md`](ОТЧЁТ_ЭТАПЫ_3-5.md) и [`dga/ОТЧЁТ_DGA.md`](dga/ОТЧЁТ_DGA.md).

## Как устроено

```
 .pcap ─▶ pcap_parser.py ─┬─▶ dga/dga_detector.py ──────┬─▶ fusion.py ─▶ report_generator.py ─▶ report.html
          (DNS и          │   имя домена → 0–1           │   риск = 1 − (1 − 0,8·DGA)(1 − 0,9·поведение)
           соединения)    └─▶ behavior_analyzer.py ──────┘
                              NXDOMAIN, всплески, маячки, IP без DNS, сканирование
```

| Файл | Участник | Что делает |
|---|---|---|
| `main.py`, `fusion.py`, `report_generator.py` | Басыбек М | запуск, объединение оценок, отчёт |
| `pcap_parser.py` | Солтанбек Б | pcap/pcapng → таблицы DNS и соединений, удаление дублей |
| `dga/` | Жумажанов Н | детектор DGA: 13 признаков, Random Forest, UMUDGA |
| `behavior_analyzer.py` | Нурсоветов А | поведенческие признаки хоста |
| `tools/`, `fake_*.ps1` | Макушев К | генератор размеченных сетей, эксперименты, скрипты для показа |

## Папки

```
КОМАНДЫ/          команды по шагам
pcaps/demo/       демо-запись офисной сети (+ .truth.json: кто заражён на самом деле)
pcaps/real/       реальные записи вредоносного трафика (Stratosphere Lab)
dga/              детектор DGA, данные UMUDGA, обученная модель
tools/            генератор сценариев, эксперименты, сборка витрины
results/          результаты экспериментов
showcase/         страница-витрина с результатами и примерами отчётов
tests/            тесты
demo.bat          демонстрация одной кнопкой
fake_user.ps1     имитация обычного пользователя (для чистой записи)
fake_infected.ps1 безопасная имитация заражённого компьютера
```
